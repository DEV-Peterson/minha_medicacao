# Minha Medicação

![Minha Medicação — lembretes de remédio sem esquecer a dose](imagens/banner.png)

Aplicativo Android gratuito para organizar remédios: mostra o que tomar e a que
horas, avisa no horário, registra as doses e acompanha o estoque. Funciona sem
internet, sem cadastro e sem anúncios. É um projeto pessoal, sem fins
lucrativos, feito para ajudar pessoas.
